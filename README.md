# Comunidade de Estudos

MVP acadêmico em Python 3.12: grupos de estudo, tarefas e colaboração, com dados fictícios e menu de terminal.

```powershell
py -3.12 main.py
```

Sem dependências externas. Em outros sistemas: `python main.py`.
